# TickTick Weekly Checklist

**Last updated:** 2026-05-17 (America/New_York)
**Owner:** Founder (personal execution) — derived from `current-sprint.md` and `coordinator-weekly-sync.md`
**Purpose:** A short, repeatable checklist the founder follows manually in TickTick each week. Personal check-off layer only — not the project brain. Repo docs remain source of truth.

Keep this practical. If a week is heavy (founder capacity, R-CAP-1), do the Monday and Friday lists only.

---

## Monday — Plan (≈15 min)

- [ ] Read `CURRENT_STATE.md` and `docs/project-control/current-sprint.md`
- [ ] Confirm the sprint goal still makes sense
- [ ] Pick the 1–3 tasks that actually matter this week
- [ ] Move only those into TickTick "KeepMees - This Week"
- [ ] Note any decision you owe the Coordinator
- **Update in repo:** nothing yet (planning only)
- **Ask Coordinator:** anything blocking this week's 1–3 tasks?

## Midweek — Correct (≈10 min, Wed/Thu)

- [ ] Check progress vs. the 1–3 tasks
- [ ] Move blocked items to "KeepMees - Waiting / Blocked" with a one-line reason
- [ ] If a task is stuck, reduce scope rather than push harder (capacity-aware)
- **Update in repo:** `kanban-board.md` card moves (or note for Friday)
- **Ask Claude:** only a concrete, scoped next step — not open-ended exploration

## Friday — Closeout (≈20 min)

- [ ] What got done? Check it off
- [ ] What carries over? Keep it; don't pile on
- [ ] Run the Project Control Sync items (see `coordinator-weekly-sync.md`)
- [ ] Note decisions made this week
- **Update in repo:** `current-sprint.md`, `kanban-board.md`, `CURRENT_STATE.md` if state changed; add a `coordinator-weekly-sync.md` log line
- **Ask Coordinator:** confirm next week's priority / next package authorization if relevant

## Sunday — Reset (optional, ≈15 min)

- [ ] Skim `master-schedule.md` and `next-7-days.md`
- [ ] Sanity-check confidence labels (anything slipped to Low?)
- [ ] Decide what NOT to do next week (defer list)
- **Update in repo:** `next-7-days.md` for the coming week
- **Defer, don't drop:** move non-urgent items to "KeepMees - Someday / Deferred"

---

## What to defer (don't let these creep in weekly)

- Vendor outreach (gated)
- Design hiring (paused)
- Checkout / PDF / preview renderers (gated)
- n8n/Make/Zapier automation (later)
- Package 5A work before Tower approval

## Rule

TickTick holds this week's check-offs and reminders only. The backlog, roadmap, gates, decisions, and risks live in the repo. If TickTick and the repo disagree, the repo wins — fix TickTick.
